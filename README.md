# WalletHot Android 测试安装包

[下载最新测试版](https://github.com/HPF-10086/UpdataAPK/releases)

这里仅提供 WalletHot 的 Android APK、SHA-256 校验文件和版本说明，不包含源码、签名密钥或钱包数据。

- 普通安卓手机选择 `arm64.apk`，x64 用于模拟器。
- 覆盖安装可保留原有钱包和数据；不要先卸载、清除数据或降级。
- 仅支持 TRON Shasta 测试网，测试资产无真实价值，不能用于主网资产。
- 使用开发签名，仅供测试。系统兼容性请以实际设备测试为准。
